Creates a new user record in SQLite with a securely salted password hash using Werkzeug.

Request JSON Payload:
{
  "name": "Alex Smith",
  "email": "alex@example.com",
  "password": "Password@123"
}
Response JSON (201 Created):
{
  "success": true,
  "message": "User registered successfully.",
  "data": {
    "user": {
      "id": 2,
      "name": "Alex Smith",
      "email": "alex@example.com",
      "created_at": "2026-08-21T02:10:00.000000"
    }
  }
}

Validates credentials and generates a signed JWT token valid for standard requests.

  }

Creates a new feature record. Must include header Authorization: Bearer <JWT>.

Request JSON Payload:
{
  "title": "Cloud Storage Sync",
  "description": "Bi-directional sync with S3/GCS buckets.",
  "category": "Infrastructure",
  "status": "Active"
}
Response JSON (201 Created):
{
  "success": true,
  "message": "Feature created successfully.",
  "data": {
    "feature": {
      "id": 6,
      "title": "Cloud Storage Sync",
      "category": "Infrastructure",
      "status": "Active"
    }
  }
}

Updates fields on the feature corresponding to <id>.

Request JSON Payload:
{
  "title": "Updated Feature Name",
  "status": "Inactive"
}
Response JSON (200 OK):
{
  "success": true,
  "message": "Feature updated successfully.",
  "data": { "feature": { "id": 1, "status": "Inactive" } }
}
